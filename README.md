## 📖 Sobre este Repositório

Este repositório tem como objetivo **compilar, organizar e documentar** os materiais de React produzidos por **Matheus Battisti** — incluindo cursos no YouTube, cursos na Udemy, e-books e projetos práticos.

A iniciativa serve como um **guia de referência** para desenvolvedores que desejam aprender React de forma estruturada, aproveitando o conteúdo de qualidade produzido em português pela comunidade brasileira.
