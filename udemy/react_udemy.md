## 📋 Legenda dos Campos

| Campo | Descrição |
|-------|-----------|
| **Título** | Nome oficial do curso conforme a plataforma |
| **Plataforma** | Onde o curso está hospedado (Udemy, YouTube, Alura, etc.) |
| **Instrutor** | Nome do professor ou instituição responsável |
| **Duração (h)** | Carga horária total de vídeo-aulas |
| **Gratuito (S/N)** | `S` = gratuito · `N` = pago (incluir preço nas observações, se relevante) |
| **Nível** | Iniciante · Intermediário · Avançado |
| **Idioma** | Idioma principal das aulas |
| **Avaliação (⭐)** | Nota média de 0 a 5 na plataforma |
| **Alunos** | Número total de alunos inscritos |
